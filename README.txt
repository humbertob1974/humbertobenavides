LANDING PAGE — HUMBERTOPENAVIDES.COM

Archivos:
- index.html: página completa, estilos y animaciones.

PUBLICACIÓN RÁPIDA
1. Sube index.html a la carpeta pública de tu hosting, normalmente public_html.
2. Asegúrate de que el dominio humbertobenavides.com apunte a ese hosting.
3. Reemplaza contacto@humbertobenavides.com por tu correo real.
4. Reemplaza el enlace genérico de LinkedIn por tu perfil real.

PERSONALIZACIÓN
- Colores: variables CSS al inicio del archivo, dentro de :root.
- Textos: busca cada sección por su encabezado.
- Logo: actualmente usa las iniciales HB.
- Calendario: reemplaza los enlaces mailto por tu enlace de Calendly o Google Calendar.

La página funciona sin librerías externas, excepto Google Fonts.
