# Benavides Trusted Advisors — sitio estático

Paquete listo para publicar con GitHub Pages en `humbertobenavides.com`.

## Publicación

1. Coloque todos los archivos de esta carpeta en la raíz de la rama `main` del repositorio.
2. En GitHub, abra **Settings → Pages**.
3. En **Build and deployment**, seleccione **Deploy from a branch**.
4. Elija la rama **main**, la carpeta **/(root)** y guarde.

El archivo `CNAME` ya contiene el dominio personalizado.

El sitio incluye selector **ES / EN**, navegación móvil, animaciones suaves y la sección ejecutiva **Situaciones en las que podemos ayudar**.

El archivo `bta-logo.png` contiene el logotipo oficial utilizado en el encabezado y el pie de página.
